# TFT AI Coach Worker

Cloudflare Worker that powers the AI Coach chat widget on the dashboard. It retrieves the most relevant
chunks from `docs/api/rag_context.json` (regenerated by the pipeline on every run) and asks the Gemini API
to answer using only that context.

```
Browser widget  ->  Cloudflare Worker  ->  rag_context.json (GitHub Pages)
                                       ->  Gemini API (key stored as a Worker secret)
```

## Deploy

Requirements: Node.js 18+, a free Cloudflare account and a Gemini API key from https://aistudio.google.com/apikey

```bash
cd worker
npx wrangler login
npx wrangler secret put GEMINI_API_KEY
npx wrangler deploy
```

`wrangler deploy` prints the Worker URL, for example `https://tft-ai-coach.<your-subdomain>.workers.dev`.

## Connect the dashboard

1. GitHub repository -> Settings -> Secrets and variables -> Actions -> **Variables** tab
2. Create a repository variable `CHAT_WORKER_URL` with the Worker URL
3. Run the workflow manually (Actions -> TFT Meta Pipeline -> Run workflow, `force_rebuild = true`)

The widget switches from "coming soon" to live once the page is rebuilt.

## Configuration (`wrangler.toml`)

| Variable | Purpose |
| :--- | :--- |
| `SITE_URL` | Site that serves `api/rag_context.json` |
| `ALLOWED_ORIGINS` | Comma-separated origins allowed to call the Worker (CORS + origin check) |
| `GEMINI_MODEL` | Gemini model id |
| `RATE_LIMIT_PER_MINUTE` | Best-effort per-IP request limit |
| `GEMINI_API_KEY` | Secret, set with `wrangler secret put` |

## Local test

```bash
npx wrangler dev
curl -X POST http://localhost:8787 \
  -H "Origin: https://apexq.github.io" -H "Content-Type: application/json" \
  -d '{"message":"What is the best AP comp right now?","lang":"en"}'
```

## Hardening notes

- The origin check only blocks browsers on other sites; scripts can still spoof the header. Add a
  Cloudflare Rate Limiting rule (Security -> WAF -> Rate limiting rules) for stronger abuse protection.
- Set a spending cap or stay on the free tier in Google AI Studio so abuse cannot generate costs.
