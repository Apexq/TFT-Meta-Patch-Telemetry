# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, authentication issue, data leak, or Riot Games Developer Policy concern within this platform, **please do not open a public GitHub issue**.

Instead, report it privately via **GitHub Private Vulnerability Reporting** under the **Security** tab of this repository.

Please include:
- A clear description of the issue and affected endpoint or component.
- Steps to reproduce or minimal proof-of-concept details.
- Potential impact assessment.

Reports are reviewed promptly, and confirmed findings are remediated before any public disclosure.

## Scope Notes

- This is a hosted proprietary web application; third-party local installations or forks are unsupported.
- Live API credentials, user session tokens, and infrastructure configurations are never stored in source control.
